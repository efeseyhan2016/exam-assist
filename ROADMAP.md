# EXAM ASSIST Roadmap

## Current Stage

EXAM ASSIST is in a foundational product-shaping stage.

The product already has:
- onboarding
- app shell
- sidebar navigation
- Home direction
- approaching exams / next exam
- study logging
- priorities / risk layer
- local-first persistence
- schedule intake/import

But it still needs:
- stronger model integrity
- stronger data integrity
- cleaner information architecture
- stronger confidence in the planning engine
- tighter product discipline

---

## Phase 1 — Strong Foundation

### Goal
Make the current product credible, clear, and stable.

### Focus
- model integrity
- data integrity
- micro-pack cleanup
- honest UI presentation
- architecture cleanup
- test coverage for core logic

### Priority examples
- remaining-capacity realism
- shared-capacity realism
- sleep/urgency realism
- local storage validation
- timezone explicitness
- risk confidence honesty
- input validation
- storage recovery handling

This is the most important phase.

---

## Phase 2 — Core Product Usefulness

### Goal
Make EXAM ASSIST genuinely useful in daily student workflow.

### Focus
- stronger onboarding
- personalization
- language selection
- PDF/resource handling
- task/assignment/project support
- stronger "what should I do now?" guidance

### Priority examples
- useful onboarding
- Turkish/English support
- profile context (student / worker, department / role)
- PDF upload / resource library
- tasks / assignments / projects
- better study action guidance

This phase should deepen utility without exploding scope.

---

## Phase 3 — Academic Depth

### Goal
Expand from exam-week planner into a broader academic workspace.

### Focus
- grade history
- exam result tracking
- richer planning surfaces
- daily briefings
- stronger academic context

### Priority examples
- exam history
- score tracking
- assessment type tagging (midterm / final / etc.)
- simple grade history
- daily briefing surfaces

This phase should make the product richer, but still focused.

---

## Phase 4 — Intelligence Layer

### Goal
Add smart but trustworthy assistance.

### Focus
- recommendation quality
- AI assistance
- personalized planning support
- better summaries

### Important rule
AI should only be added after the non-AI product is already strong.

AI is not the foundation.
It is a later layer.

---

## Phase 5 — Optional Expansion

### Possible future directions
- collaboration
- group study
- social features
- richer note systems
- deeper integrations

### Important rule
These are explicitly secondary.

They should only be considered if they strengthen the core product and do not turn EXAM ASSIST into an unfocused platform.

---

## Priority Principle

Not everything is equally urgent.

Order of importance:
1. trustworthiness
2. clarity
3. priorities/planning value
4. stable data flow
5. stronger usefulness
6. broader feature depth
7. optional expansion

---

## Final Roadmap Rule

EXAM ASSIST should grow by becoming better at its core before becoming bigger at the edges.
